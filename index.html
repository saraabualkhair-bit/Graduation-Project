01 Project Overview
This project involves a comprehensive analysis of a Supply Chain dataset, spanning data modeling, cleaning, exploratory analysis, and predictive forecasting. The goal is to uncover actionable insights for decision makers by answering key analysis and forecasting questions, culminating in an interactive Tableau visualization dashboard and a final presentation report.
